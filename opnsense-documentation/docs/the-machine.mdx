# The machine

OPNsense arrives as an image you boot, then as a system you install onto a disk. The download page is [opnsense.org/download](https://opnsense.org/download/). Take **amd64**. **dvd** is the right file for a virtual machine. **vga** is the one you write to a USB stick when a monitor is attached.

Check the SHA-256 the way the [install chapter](https://docs.opnsense.org/manual/install.html) asks. Unpack a `.bz2` before you attach or write the image.

## A virtual lab

Any hypervisor that runs FreeBSD is in scope: VirtualBox, VMware, Hyper-V, KVM. The project’s own note is [virtual and cloud install](https://docs.opnsense.org/manual/virtuals.html).

| | |
| --- | --- |
| Guest type | BSD / FreeBSD (64-bit) |
| Memory | 3072 MB. Three gigabytes is the floor, not a suggestion. |
| Disk | 16 GB is comfortable for a lab |
| First adapter | LAN. Host-only or internal. |
| Second adapter | WAN. NAT, or bridged if you want a real upstream DHCP. |

Attach the ISO to the optical drive. If you later want guest additions under VirtualBox, that is the plugin `os-virtualbox` in **System → Firmware → Plugins**, after the system is installed. It is not a file in this repository.

## Hardware, if you are not in a VM

Write the USB image with `dd`, Etcher, or Rufus. Boot it. You want two ports if LAN and WAN should be different networks. Eight gigabytes of disk is a practical minimum. Two gigabytes of RAM will boot. Three is what the virtual guide treats as the minimum worth using.

## What you will not find

There is no official `docker compose` service for this appliance. Images on the download page are dvd, vga, serial, and nano. If a blog shows a container named OPNsense, it is not the image Deciso publishes.
