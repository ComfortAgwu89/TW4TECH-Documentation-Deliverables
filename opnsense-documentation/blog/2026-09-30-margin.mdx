The handbook at [docs.opnsense.org](https://docs.opnsense.org/) is already the book. My mistake was trying to compete with it. What I needed was a margin: the three facts that stall a first boot, written where I can see them without searching.

{/* truncate */}

## The margin

The live installer is `installer` / `opnsense`. The GUI is `root`, on `https://192.168.1.1/`, until you move the LAN. There is no official Docker image. The download is an ISO from [opnsense.org/download](https://opnsense.org/download/), and virtual machines are described at [docs.opnsense.org/manual/virtuals.html](https://docs.opnsense.org/manual/virtuals.html).

## The door

Once the page loads, scripts use the same house. HTTP Basic, key then secret, path `/api/<module>/<controller>/<command>/`. The how-to I keep pinned is [Use the API](https://docs.opnsense.org/development/how-tos/api.html). The code is [github.com/opnsense/core](https://github.com/opnsense/core).

I do not need a second product in this repository to have something to curl. The appliance is the product.
